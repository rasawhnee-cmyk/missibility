# Template Library (28 working assets)

Build these as spreadsheets (.xlsx/Sheets) or markdown tables. Field lists for the most-used assets are in the referenced files; this file lists every asset, its purpose, and core fields.

## Controlled field formats
| Type | Format |
|---|---|
| ID | Uppercase prefix + number: TOP-001, SRC-014, PRM-032, ENT-006, CLM-010, INC-004, KW-0001 |
| Date | YYYY-MM-DD |
| Boolean | Yes / No / Unknown |
| Status | Not Started · In Progress · Blocked · In Review · Approved · Published · Monitoring · Resolved · Retired |
| Priority | P0 · P1 · P2 · P3 |
| Score | Whole number within defined scale |
| Owner | Named role or person |
| Trend | Growing · Stable · Declining · New · Insufficient Data |
| Confidence | High · Medium · Low |

Blank = not applicable/not entered. Zero = measured zero. Unknown = should exist but unverified. Never mix them. Link records by ID instead of copying text.

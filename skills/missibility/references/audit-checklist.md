# Master Search Visibility Audit

Use before building a large roadmap. Don't convert every unchecked item into an urgent task — find the small number of constraints blocking the largest business value and fix those first. For each section, mark Yes / Partial / No / Unknown, add evidence, and score the matching Search Visibility System dimension 0–2.

1. **Business alignment** — Priority products/services defined? Target customers? Qualified demand defined? Margin, deal value, capacity understood? Search has a business KPI?
2. **Customer research** — Sales calls, lost deals, support questions, reviews/communities reviewed? Keyword Universe exists? Prompt Universe exists? Synthetic prompts labeled?
3. **Prioritization** — Search Opportunity Map exists? Each priority topic has BV, Demand Confidence, RtW, Gap, Evidence, Effort? Every topic ends with an action decision?
4. **Technical foundation** — Correct status codes on priority URLs? Major crawlers reach them? Index directives correct? Canonicals coherent? Sitemaps clean? Important pages internally linked? JS content renders? WAF rules reviewed? Release QA includes Search?
5. **Crawler governance** — Googlebot · Google-Extended (separately) · Bingbot · OAI-SearchBot · GPTBot · ChatGPT-User understood · PerplexityBot · Perplexity-User understood · ClaudeBot / Claude-SearchBot / Claude-User separately · all relevant subdomains reviewed?
6. **Entity governance** — Entity Register? Company/product/person/location/certification facts consistent? Structured data agrees with visible copy? External profiles accurate?
7. **Source of Truth** — Every material fact type has an authoritative record? Owners defined? Conflicts stop publication? Version history?
8. **Evidence** — High-value claims evidenced? Case studies with verified detail? Original research with methodology? Experts named? Limits stated?
9. **Information architecture** — One Core Source per major topic? Supporting Sources add depth? Evidence Sources connect to claims? Duplicate-purpose pages controlled? Internal links follow decisions?
10. **Page quality** — Page Contract per priority page? Answers early? Claims supported nearby? Distinct information? Meaningful dates? CTA fits intent? Owner + refresh trigger?
11. **AI content operations** — Source Pack? Fields labeled Locked/Transformable/Generative/Human Only? Risk tiers? Factual QA before polish? Unsupported claims block publication? Publishing permissions separate?
12. **Prompts & agents** — One job per prompt? Prompt Contract? Source rules? Conflict & failure states? Untrusted inputs separated? Read/write separated? Evaluation set?
13. **Source reuse** — Every derivative has a parent and a job? Facts and limits inherited? Distance sets review? Parent changes trigger dependent review?
14. **Authority** — Authority Map? Experts mapped to topics? Source-worthy evidence owned? Publications, associations, partners, customer proof mapped? Earned vs paid separated?
15. **GEO** — Citation Opportunity Map? Priority claims owned? Citation Readiness Scores on priority pages? Citations distinguished from rankings? Grounding Queries distinguished from prompts? Commercial citation gaps identified?
16. **Representation** — Golden Fact Set? Company/product/people/location facts tested? Wrong answers traced to sources? Severity assigned? High-risk incident workflow? Old PDFs audited?
17. **Platform playbooks** — Google: Googlebot access, Google-Extended separate, generative impressions reviewed, multimodal relevant? ChatGPT: OAI-SearchBot allowed where desired, GPTBot separate, ChatGPT-User understood, chatgpt.com referrals reviewed? Bing/Copilot: Bingbot allowed, IndexNow, AI Performance reviewed, Grounding Queries & Citation Share interpreted correctly? Perplexity: PerplexityBot allowed, WAF tested, Perplexity-User understood, modes tested separately? Claude: three bot policies separate, public vs connected tests separate, direct URL fetch tested?
18. **Measurement** — Metric Dictionary? Native vs internal metrics labeled? Citations separate from traffic? Brand mentions separate from owned citations? Representation accuracy tracked? Business outcomes visible?
19. **Operations** — One accountable Search owner? One backlog? Weekly/monthly/quarterly/annual cadences? Decision Log? Refresh system? Incident system? Maintenance capacity?
20. **Economics** — Agreed budget? Internal labor counted? Evidence, technical work, maintenance funded? Tools have owners? Scenarios? Pipeline separated from revenue? Kill and scale rules?

Audit output: section table (status, evidence, confidence) → Search Visibility System Score (/24) → top 3–5 constraints by business value → 90-day sequence (see `measurement-operations.md`).
